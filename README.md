# 地铁行车核心仿真（CBTC 风格）

浏览器内的地铁列车运行核心：闭塞分区驱动的移动授权、ATP 超速防护制动曲线、
带迟滞与电空转换的车辆动力学、±30cm 对标停车与屏蔽门联动，WebGL2 三维线路渲染。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm test           # 21 个单元/集成/车队浸泡测试
npm run build      # 类型检查 + 生产构建
```

## 操作

| 按键 | 功能 |
|---|---|
| W / S | 牵引手柄 ±10% |
| ↑ / ↓ | 制动手柄 ±10% |
| Backspace | 手柄回零 |
| 空格 | 人工紧急制动；紧急制动停稳后按此确认缓解 |
| R（按住场景） | 停过标后进入退行模式（限速 10 km/h） |
| L | 切换满载 AW3 / 空载 AW0（须停稳） |
| T | 车门状态查询（开关门由停站流程自动管理） |
| C | 切换视角：跟随 / 俯视 / 全局 |
| 1 | 测试场景：前车区间紧急停车，验证后车 ATP 拦截 |

## 仿真架构

固定步长 **120 Hz** 物理步进（`src/sim/world.ts`），渲染与物理解耦，
渲染帧用累加器追赶物理时间，切后台不会产生追帧螺旋。

```
src/sim/
  config.ts    全局参数与列车状态类型（SI 单位）
  mathutil.ts  一阶惯性环节、环线距离、固定步长累加器
  line.ts      20 站环线生成：闭塞分区、坡度、曲线、限速、车站
  signal.ts    固定闭塞占用检测、移动授权、三显示信号机
  atp.ts       制动曲线 v=√(v₀²+2ad)、报警/E-B 两级阈值、缓解条件
  dynamics.ts  牵引恒功率衰减、电制动低速退出、空气制动补足、
               Davis/坡道/曲线阻力、静止防溜、退行限速
  station.ts   对标判定（±30cm）、车门/屏蔽门联动、停过标退行状态机
  driver.ts    AI 司机（ATO）：追踪防护 + 运动学精确停车
  world.ts     12 列车世界主循环
src/render/
  renderer.ts  WebGL2 轨道/信号机/站台/列车/占用分区渲染，三种相机
src/ui/
  hud.ts       仪表 HUD 与 2D 制动曲线迷你仪表
```

## 关键安全机制

1. **移动授权**：每步重算分区占用；授权终点回溯到阻挡列车连续占用区的
   最后端边界，并保留 80m 安全距离覆盖制动缸建立迟滞。
2. **ATP 曲线**：保证减速度取保守的 0.7 m/s²（低于实际可用值），
   超速 2 km/h 报警、超速 4 km/h 触发锁存式紧急制动；
   必须**停稳 + 人工确认 + 速度回到曲线内**才能缓解。
3. **防溜**：无牵引且速度低于 0.5 m/s 时自动施加保持制动，
   非退行模式下速度过零硬钳位，坡道上不会溜车。
4. **对标**：停在停车标 ±30cm 内才开车门与屏蔽门；
   越过 2m 判为 overshoot，强制退行重新对标；停站 20s 自动关门。
