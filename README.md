# 地铁司机模拟 · ATP 防护行车（WebGL2 + TypeScript）

在浏览器里实现的地铁列车驾驶核心：固定闭塞信号、车载 ATP 超速防护、带坡道/曲线阻力和
电空制动混合的车辆动力学、±30 cm 对标停车，以及一条 20 站线路上 12 列车的自动追踪运行。

## 运行

```bash
npm install
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm test           # 仿真单元测试（vitest）
npm run build      # 类型检查 + 生产构建
```

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `S` | 牵引升 / 降（4 级） |
| `D` / `A` | 制动升 / 降（7 级） |
| `R` / `N` / `F` | 反向器 前进 / 零位 / 后退 |
| `空格` | 司机紧急制动按钮 |
| `Q` | EB 停稳后确认缓解 |
| `E` | 关闭车门 / 屏蔽门 |
| `X` | 过标后申请退行（限速 5 km/h，超速触发惩罚制动） |
| `C` | 切换视角（追尾 / 驾驶室 / 环绕） |

## 架构

```

    types.ts           共享类型
    rng.ts             确定性随机数（线路可按种子复现）
    line.ts            20 站线路生成：闭塞分区、坡道、曲线、限速、中心线几何
    signaling.ts       固定闭塞占用、移动授权、三显示信号（绿/黄/红）
    atp.ts             ATP 监督：报警曲线 + 紧急制动曲线、EB 锁存与确认缓解
    train.ts           车辆纵向动力学 + 停站/折返/退行状态机
    aiDriver.ts        11 列 AI 车的自动牵引制动、对标、折返
    world.ts           固定步长总控（100 Hz）、12 列车调度
    *.test.ts          18 个单元测试
  render/              原生 WebGL2 渲染层（无三方 3D 库）
    math3d.ts          mat4/vec3 数学
    shaders.ts         GLSL ES 3.00 着色器
    gl.ts              程序编译、VAO、实例化灯泡网格
    mesh.ts            轨道/地面/站台/信号机/列车网格构建
    renderer.ts        场景渲染、三种相机
    hud.ts             2D 仪表：速度表、ATP 制动曲线、信号复示器、对标误差
    input.ts           键盘输入
  main.ts              固定步长累加器主循环
```

## 关键模型

### 信号与移动授权
- 线路按固定闭塞分区切开（约 460 m，车站处对齐）。
- 每列车按车头、车尾、中点占用其覆盖的全部分区。
- 后车移动授权终点 = 前方第一个被占分区的入口（留 50 m 安全余量）。
- 信号机三显示：本分区占用红灯、下一分区占用黄灯、否则绿灯。

### ATP 制动曲线
- 对每个监督目标（授权终点、限速下降点、线路尽头、AI 站停点）构建
  恒减速度曲线 `v² = v_target² + 2·a·d`，取所有曲线的最严值。
- 紧急曲线用保证减速度 1.0 m/s²；报警曲线用 1.25 倍，故报警线在紧急线上方。
- 速度碰报警线→声光报警；碰紧急线→施加紧急制动并锁存。
- EB 必须等列车停稳保持 1 秒后，司机按 `Q` 确认才能缓解；缓解后进入抑制态，
  列车重新回到曲线下方才恢复监督，避免停在红灯前被反复触发。

### 车辆动力学
- 牵引：恒力区到切换速度，之后恒功率，牵引力随速度下降；带一阶响应滞后。
- 制动：电制动在 3 m/s 以上全可用、0.6 m/s 以下完全退出，中间线性淡出，
  不足部分由空气制动补偿（空气制动充风/排风都有时间常数）。
- 制动手柄位请求的是**固定比例的硬件制动力**，因此同一手柄位下空载减速度明显大于满载。
- 阻力：Davis 公式 `A+Bv+Cv²`、坡道阻力 `mg·grade`、曲线阻力 `w=700/R`（N/kN）。
- 静止停放制动、牵引/制动联锁、防滑钳制均有建模。

### 对标停车
- 停车标前后 30 cm 内停准才开启屏蔽门；停过标进入过标状态，按规定退行（限速 5 km/h）；
  过标超过 15 m 记为失败停站。
- 停站判定要求持续低速 0.5 秒，避免蠕行被误判为停稳。

### 实时性
- 仿真固定 100 Hz 步长（每秒 100 次更新，满足 ≥60 次/秒要求），与显示帧率解耦。
- 实测 12 列车跑 600 仿真秒仅需约 9 秒墙钟（约 70 倍实时），单步平均 0.14 ms。
